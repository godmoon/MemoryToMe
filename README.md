# MemoryToMe · 记忆小站

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Node.js](https://img.shields.io/badge/Node.js-%3E%3D22.5-339933?logo=node.js&logoColor=white)](https://nodejs.org/)
[![CI](https://github.com/godmoon/MemoryToMe/actions/workflows/ci.yml/badge.svg)](https://github.com/godmoon/MemoryToMe/actions/workflows/ci.yml)

给小学生的语文听写 + 艾宾浩斯复习小站。每天按记忆曲线挑出该听写的词，孩子听、写、自己批改，第二天错的词会再回来。

纯网页应用：手机、平板、电脑都能用，支持触屏、鼠标和键盘。数据保存在本机，不需要注册账号。

> 每天 10 分钟，把生字写进长期记忆。

## 功能一览

- **语文听写**：按曲线自动生成当天词单，默认 20 个词，可改成 1–100 个。
- **逐词听写**：一次只出现一个词，显示拼音和字数提示，自动朗读，可随时“按住偷看”。
- **不会就标红**：听写时可以把不会的词标红，进入批改页会自动带出来。
- **点字批改**：默认全对，点单个字只标这个字，点词的空白处会把整词所有字一起标红；提交后自动安排下次复习时间。只听了一部分也能先批改，没听过的词不参与计分。
- **易错字复习**：成绩页会列出本次标红的字，可以单独练或生成默写单；“易错字”页面按错误次数汇总全库易错字，支持搜索、朗读、单字练习和打印默写单。
- **词语档案**：每个词都有听写次数、成功次数、正确率、当前阶段和下次到期日。
- **批量管理**：词库页可进入批量模式，跨页选择词语，批量重置进度、暂停/恢复、删除，或把选中的词按列表顺序提前到下次听写的最前面。除了手动勾选和全选，还可以粘贴“一行一个词语”的清单，自动匹配词库并选中。
- **GitHub 风格热力图**：一年听写日历，按词查看首次加入、红/绿历史和每次听写结果。
- **易错词**：自动收集错过的词，可以单独查看、立即重练或暂停。
- **教材词库**：内置统编版小学语文 12 册生字、组词和词语表，可以按册挑词导入。
- **英语认词**：独立的英语页面，看英文认中文，点开释义后选“记住了 / 没记住”，内置小学到考研词库。
- **多种导入**：粘贴文本、CSV、JSON、教材词库、英语词包。
- **三种主题**：暖纸、夜读、薄荷；桌面侧栏、手机底栏。
- **备份与重置**：导出 JSON 备份，或清空进度重新开始。

## 快速开始

需要 **Node.js 22.5 或更高版本**（使用内置的 `node:sqlite`，不需要编译原生模块）。

```bash
git clone https://github.com/godmoon/MemoryToMe.git
cd MemoryToMe
npm install
npm start
```

打开 <http://localhost:3001>。同一局域网内的手机可以访问启动日志里显示的局域网地址。

开发时可以自动重启：

```bash
npm run dev
```

长期运行推荐用 PM2（配置见 `ecosystem.config.cjs`，默认端口 3001）：

```bash
pm2 start ecosystem.config.cjs
pm2 save
pm2 logs memorytome
```

常用管理命令：

```bash
pm2 restart memorytome   # 重启
pm2 stop memorytome      # 停止
pm2 delete memorytome    # 删除进程
pm2 status               # 查看状态
```

如果服务器重启后需要自动拉起，执行一次 `pm2 startup`，再按提示运行它输出的命令。

可选环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3001` | 服务端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | `./data` | 数据目录 |
| `DB_PATH` | `$DATA_DIR/memorytome.db` | 数据库文件路径 |

例如把测试数据放到临时目录：

```bash
PORT=3002 DATA_DIR=/tmp/mt-test npm start
```

> 首次启动会自动建库。`node:sqlite` 在部分 Node 版本会打印一条 ExperimentalWarning，不影响使用。

## 使用流程

1. **导入词库**：进入“导入”，粘贴自己的词，或从教材里按册挑字词。
2. **开始听写**：在“今日”点开始，听到/看到提示后写在纸上。
3. **标出不会的**：不会就点“不会，标红”，或者先跳过，批改时再点。
4. **批改**：听写结束后进入批改页，点单个字只标这个字，点词的空白处会把整词所有字一起标红，其余默认算对。如果今天只听了其中一部分，也可以直接去批改：批改页只显示已经听过的词，没听过的词不会被算错，也不会被安排复习。
5. **提交**：系统按结果安排下次出现时间，并更新统计和热力图。只批改了一部分时，这次听写会保持“进行中”，下次可以从没批改的词接着听、接着批。
6. **第二天**：到期的词、最近错过的易错词会自动排进新一天的词单。
7. **批量整理**：在词库页点“批量管理”，勾选词语后可批量重置进度、暂停/恢复或删除。支持全选本页、全选当前筛选结果、输入选词，选择会跨页保留，底部浮条会显示已选数量。也可以用鼠标拖动，或在手机上按住词卡后滑动，连续选择多个词语。
8. **提前复习**：勾选词语后点“提前复习”，这些词会按列表顺序排到下次听写的最前面（越靠前越先复习），不会立刻跳去练习。等下次在主页点“听写”时，它们会先出现，卡片上也会显示“已提前”。如果今天已经有进行中的练习，会直接插到还没做的词前面，不会打乱已完成的进度；今天已经答过的词不会重复安排。真正答完这个词后，“已提前”标记会自动清除。

### 键盘快捷键

听写页：

| 按键 | 作用 |
| --- | --- |
| `←` | 上一个词 |
| `→` / `空格` / `回车` | 下一个词 |
| `S` | 再朗读一遍 |
| `P` | 显示/隐藏拼音（英文模式为显示/隐藏释义） |

批改页和词库页也支持键盘操作：按钮可用 `Tab` 聚焦、`回车` 触发；词库卡片可用 `回车` 或 `空格` 打开。

### 手机使用

- 页面按 390px 宽度做了适配，没有横向滚动。
- 可以把网页“添加到主屏幕”，像小应用一样打开。
- 朗读使用浏览器自带的语音合成，声音取决于设备已安装的语音包。

## 复习算法

### 间隔序列

基础节点参考艾宾浩斯遗忘曲线，并结合 SM-2 的难度系数：

```
第 1 次成功 → 1 天
第 2 次成功 → 2 天
第 3 次成功 → 4 天
第 4 次成功 → 7 天
第 5 次成功 → 15 天
第 6 次成功 → 30 天
之后        → 60 / 120 / 180 天
```

- **答对**：阶段 +1，熟练度 `ease` 小幅上升（上限 2.9），实际间隔 = 基础间隔 × `ease / 2.5`。
- **答错**：阶段回退 2 级，`ease` 下降（下限 1.3），间隔重置为 1 天，第二天重来。
- 阶段 ≥ 6 且连续答对 ≥ 3 次，标记为“已掌握”，但仍会按长间隔复习。

### 每日词单怎么排

每天的目标词量默认为 20，按以下优先级挑选：

1. **到期复习**：`due_date <= 今天` 的词，越早到期越优先。
2. **易错巩固**：3 天内到期、且曾经错过的词，按错误次数排序。
3. **未来词补齐**：如果到期词不够，从未来到期的词里按时间补。
4. **今日新词**：最后加入没听过的新词，默认每天 5 个，最多不超过 `maxNew`（默认 10）。

新词和复习词默认“混合”排列，新词均匀穿插，避免连续出现太多生词。也可以改成“复习优先”或“新词优先”。

“每天总词量”是这次听写的总数上限，新词、复习词和提前复习的词都算在里面。把设置改小后，今天还没批改的会话会自动收紧到新的总数；已经批改过的词会保留，不会被删掉。

### 额外练习

当天的词单完成后，今日页会出现“额外听写 N 个”的输入框，默认 10 个，可以按 1–100 调整，数量会记在浏览器里。额外练习不受到期时间限制，会优先挑选今天还没练过的词，其次才是到期、易错和新词；词库不够时有多少练多少。

如果词被删除，导致当天的听写会话里已经没有词，这个会话会自动作废，不会继续提示“还有词没听”。

### 只听一部分也能批改

今天计划听 50 个词，孩子听到 20 个想先停，可以直接点“去批改”。批改页只会列出已经听过的 20 个词，没听过的 30 个词不会出现、不会被算错，也不会被安排复习。

- 提交后这次听写保持“进行中”，成绩页会提示还剩多少个没听，可以直接点“继续听写”从第 21 个接着听。
- 下次再批改时，只显示新听过、还没批改的词；之前批改过的词不会重复出现，也不会重复计分。
- 全部词都听完并批改后，才会显示这次听写的完整成绩。
- 听写时标红的词会自动带进批改页；没有“听过”记录的旧会话，仍按原来的方式显示全部词。

### 易错字本与默写单

批改时点红的字会按“字”单独统计，不只看整词：

- **成绩页**：本次标红的字会列在“本次易错字”里，显示每个字错了几次。点字可以单独练，也可以点“再默写一遍”生成默写单。
- **易错字页**：左侧“易错字”（手机底栏同名）按全库错误次数排队，可以搜字、拼音或词语，按错误次数/最近出错/拼音排序。
- **单字练习**：显示拼音和书写线，可以朗读、隐藏字再回忆，还能看到这个字出现在哪些词里，点词跳到词语档案。
- **默写单**：每个字给出拼音和 3 个书写格，答案统一放在底部给家长检查，支持直接打印。
- 词的下次复习仍按整词安排：只错一个字和整词都错，都会让整个词下次再听；字级统计只用于展示和专项练习。

## 导入格式

“粘贴导入”支持一行一个，也支持用逗号分隔，右上角可选“自动 / 中文 / 英文”：

```
春天
花朵,chūn duō
太阳,tài yáng,白天挂在天上会发光
apple,苹果
school,学校
```

选“自动”时会逐行判断语言，中英文可以混在同一批里导入，预览里会用“中 / EN”标出每一行的识别结果；选“中文”或“英文”则整批按这一种语言解析。

也支持：

- **CSV**：第一行可以是 `text,pinyin,meaning`、`词语,拼音,释义`、`word,meaning` 等表头。
- **JSON**：数组，或包含 `words` / `items` 数组的对象；字段支持 `text`/`word`/`词语`、`pinyin`/`拼音`、`meaning`/`释义`。
- **制表符或竖线分隔**：`词	拼音	释义` 或 `词|拼音|释义`。
- 中文词没有写拼音时会自动注音；支持带数字声调的拼音（如 `ce4 shi4 yi3`）。
- 拼音会按音节校验，`苹果,school` 这种英文单词不会被误当成拼音。
- 同一个词按“文本 + 语言”自动排重，重复导入不会产生重复记录。

## 内置教材词库

`server/seed/textbooks.json` 收录了统编版小学语文 12 册的识字表、写字表和词语表，共 4578 个生字、4403 条词语。每册可以单独挑选字词导入，导入时带上拼音、组词/例句和来源信息。

已经导入过的字词会显示“✓ 已导入”标记，导入时自动跳过；判断依据是整个词库中的中文词语，所以同一课、同一册或跨册重复出现的字词也不会重复添加。挑选时可以用鼠标拖动，或在手机上按住词语后滑动，连续选择多个字词批量导入。

数据整理自公开资料：

- <https://github.com/lm16688/xiaoxuewordslearning>
- <https://github.com/7jul/yuwen_words>

> 这是**整理版**，用于家庭听写练习。字表、拼音或组词与孩子手上的教材如有出入，可以直接在词库中编辑。教材内容的著作权归原编者及出版机构所有。

`server/seed/english.json` 是内置的英语词库，按学段分成 7 个词包，共 20168 个单词，可在“导入 → 英语词包”里按需导入：

| 词包 | 学段 | 单词数 |
| --- | --- | --- |
| 英语启蒙 · 校园与生活 | 启蒙 | 40 |
| 小学英语 · 人教三至六年级 | 小学 | 819 |
| 初中英语 · 中考词汇 | 初中 | 1986 |
| 高中英语 · 高考词汇 | 高中 | 3742 |
| 大学英语四级 · CET-4 | 大学 | 4544 |
| 大学英语六级 · CET-6 | 大学 | 3991 |
| 考研英语 · 核心词汇 | 考研 | 5046 |

词包可以叠加导入，重复的单词会自动跳过；几千词的词包在同一个事务里写入，导入完成后到左侧“英语单词”开始认词。词包里只保留单词、词性和精简后的中文释义，词典里的人名、地名等噪声会被过滤掉。

英语词条整理自公开词库 <https://github.com/KyleBing/english-vocabulary>（BSD-3-Clause），许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 英语认词

英语是单独的页面，从左侧“英语单词”（手机底栏“英语”）进入，不和语文听写混在一起，也不用在设置里切换语言。

- 一屏一个英文单词，先自己想一想中文意思。
- 点下面的“查看释义”（或按空格）查看中文释义。
- 想起来了点“记住了”，没想起来点“没记住”。
- 不用默写、不用拼写，认识就行；答完一个立刻记录，中途退出也不会丢进度。
- 当天完成后可以选“额外认 N 个”，默认 10 个，可改 1–100。
- 复习间隔和语文共用同一套记忆曲线，但两边的词库、计划和进度完全独立。

朗读使用单独的“英文语音”，可以在设置里选一个孩子听着舒服的声音。

## 数据与备份

- 所有数据保存在 `data/memorytome.db`（SQLite）。
- “导入 → 备份与重置”可以下载完整 JSON 备份，包含词库、复习记录、听写场次和设置。
- “从备份恢复”只补充词库中还没有的词，**不会覆盖已有进度**；适合换设备或合并词库。
- “重置”可以只清空复习进度保留词库，也可以连词库一起清空。操作不能撤销，建议先备份。

## 常见问题

**朗读没有声音？**
浏览器需要先有一次用户点击才能播放语音；确认设备音量、浏览器语音包和“自动朗读”开关。可以在设置里点“试听一句”。

**拼音不对？**
自动注音基于 `pinyin-pro`，多音字可能按常用读音处理。导入时写成 `词,拼音` 可以覆盖自动结果。

**今天没有词？**
说明到期词已经复习完，且新词数量为 0。可以调大“每天新词”，或再导入一些词。

**换电脑怎么迁移？**
先下载备份 JSON，在新设备上导入。注意恢复只补充缺失的词，不覆盖已有进度。
